🚀 GOLD AI HYBRID BOT - Signal Edition (Overhauled)
==========================================================

โปรเจกต์: ระบบวิเคราะห์สัญญาณเทรดทองคำ (XAUUSD) ระดับสูง (Signal-Only)
เป้าหมาย: ส่งสัญญาณเข้าเทรดที่แม่นยำ โดยเน้นให้ไม่พลาดโอกาสในจุดที่มีโมเมนตัมสูง

----------------------------------------------------------
🧠 สิ่งที่ปรับปรุงในเวอร์ชันนี้ (Overhaul Highlights)
----------------------------------------------------------
1. ตัดระบบ Trade อัตโนมัติออกทั้งหมด: เปลี่ยนเป็น Signal-Only 100% เพื่อความปลอดภัย
2. Zone-Based Entry: เลิกใช้จุดเข้าจุดเดียว (Perfect Entry) เปลี่ยนเป็น "โซนราคาที่ได้เปรียบ"
   โดยใช้ ATR ในการกำหนดความกว้างของโซนแบบ Dynamic
3. Fast-Track Trigger (SURE-SHOT):
   - หากความเชื่อมั่น (Confidence) สูงมาก (>0.88) และราคาอยู่ใน "Momentum Zone"
   - ระบบจะส่งสัญญาณ 🚀 SURE-SHOT ทันทีโดยไม่ต้องรอให้ราคาย่อถึงจุดต่ำสุดของโซน
4. Signal Layering:
   - 🔔 SETUP: พบเงื่อนไขน่าสนใจ ให้เริ่มเฝ้าระวัง
   - 🔥 STRONG SETUP: ความมั่นใจสูง แต่ราคายังไม่เข้าโซนเข้าเทรด
   - 🎯 ENTRY NOW: ราคาเข้าสู่โซนที่เหมาะสมB (Optimal Zone) และเงื่อนไขครบถ้วน
   - 🚀 SURE-SHOT: ความมั่นใจสูงสุด + โมเมนตัมแรง พร้อมเข้าเทรดทันที

----------------------------------------------------------
📂 โครงสร้างไฟล์สำคัญ
----------------------------------------------------------
1. main.py             -> ตัวขับเคลื่อนหลัก (Engine) ควบคุมการวิเคราะห์และส่งสัญญาณ
2. strategies/         -> รวมกลยุทธ์ Hybrid (SMC, OB, FVG, EMA/RSI, Institutional Flow)
3. config/settings.json -> ตั้งค่าระบบ, ไทม์เฟรม และเกณฑ์ความเชื่อมั่น (Confidence Thresholds)
4. .env                -> เก็บ Secret Keys (Discord, MT5) **(ห้ามอัปโหลดขึ้น GitHub)**
5. data/technique_weights.json -> น้ำหนักเทคนิคที่ระบบเรียนรู้ (สร้างอัตโนมัติ)
6. data/learned_params.json    -> พารามิเตอร์ RSI ที่ปรับจากผลสัญญาณ (สร้างอัตโนมัติ)
7. .gitignore          -> กำหนดไฟล์ที่จะไม่นำขึ้น GitHub เพื่อความปลอดภัย

----------------------------------------------------------
🛠️ การติดตั้งและใช้งาน
----------------------------------------------------------
1. ติดตั้ง Library ที่จำเป็น:
   pip install -r requirements.txt

2. ตั้งค่าความปลอดภัย:
   - คัดลอก .env.example เป็น .env
   - ใส่ค่า DISCORD_WEBHOOK_URL (จำเป็น) และ DISCORD_BOT_TOKEN (ถ้าต้องการ)
   - ใส่ MT5_LOGIN / MT5_PASSWORD / MT5_SERVER (ถ้าไม่ได้ login MT5 ไว้แล้ว)

3. การรันระบบ:
   - เปิดโปรแกรม MT5 และ Login บัญชี (Demo/Real)
   - รันบอทด้วยคำสั่ง:
     python main.py
